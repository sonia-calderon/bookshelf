# BookShelf

Personal library management application built with Angular. Users can organize their reading collection, track progress, manage books, and explore their library through a responsive and intuitive interface.

This project was created to practice Angular fundamentals.


## Features

- Public Area
  - Home page with project presentation
  - About page describing the application
  - Login page with form validation
- Private Area
    - Dashboard with reading statistics and library overview
    - Personal library management
        - Add new books
        - Edit existing books
        - Delete books
        - Track reading status
        - Book information
    - Gallery view to browse book covers
    - User profile page

## Technologies

- Angular
- TypeScript
- Angular Material
- Reactive Forms
- Angular Signals
- Angular Router
- SCSS

## Installation

```bash
git clone https://github.com/sonia-calderon/bookshelf.git

cd bookshelf

pnpm install

pnpm ng serve
```
